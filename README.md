# Chislopad legal pages

Static privacy pages for the Chislopad game.

## URLs

- https://bewreks.github.io/chislopad-legal/
- https://bewreks.github.io/chislopad-legal/privacy/
- https://bewreks.github.io/chislopad-legal/privacy/en/

## Publishing

The site is plain static HTML and is published with GitHub Pages from the `main` branch, repository root.

## Before store submission

- Confirm the operator name and add INN/OGRNIP and legal address if required by the store.
- Confirm the contact email.
- If advertising, analytics or other network SDKs are added, update both language versions before enabling them.
